# 3. 1.0 scope — the zero-dependency core plus a standalone backend

Status: accepted
Date: 2026-07-12

## Context
Cairn spans a zero-dependency scaffold core and an optional graphify backend.
"1.0" needs a crisp definition, and the whole project must stand alone — no
knowledge of, or dependency on, anything outside itself.

## Decision
**Cairn 1.0 = the zero-dependency scaffold core, delivered as a living
documentation system, plus the optional graphify backend — the whole project
fully standalone.** "Living" is the day-2 discipline (regenerate STATE, append
ADRs, hand-update MAP, run the audit checklist), not the backend.

- The backend ships in 1.0 as an optional, dependency-gated integration
  ([[0002-optional-graphify-backend]]).
- Public distribution (GitHub remote, marketplace) is **post-1.0**: built for the
  author now, with the standalone invariants held so publishing is a later flip.
- "Any project" is scoped to the *spine*; derived features are code-only.

## Consequences
- 1.0 gates: core hardened + tested — Cairn's own spine present + maintained —
  version single-sourced (`plugin.json`) — the "any project" claim scoped honestly
  — and the entire project provably free of any external/consumer knowledge.
- Full requirements + milestone ladder live in `ROADMAP.md`.
